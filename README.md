# Permanences — module Paheko

Permet aux membres de s’inscrire aux permanences de l’association.

## Installation

Le dossier du module est `modules/permanences/`. Utilisez ce dossier avec la procédure d’installation des modules personnalisés correspondant à votre instance Paheko. Ne déplacez pas `module.ini` hors de ce dossier.

Vérifiez la compatibilité avec la version de Paheko utilisée avant le déploiement.
